# Qleïa — Maquette interactive

Présentation : https://j-freaz.github.io/Qleia/

Accueil lounge avec présentation de l’équipe, puis sélection de trois annonces en défilement horizontal. Compatible mobile et réduction des animations.

Les fichiers à la racine publient le site avec GitHub Pages (branche main, dossier racine).

## Modifier la maquette

Décompresser `qleia-pages-source.zip`, installer Node.js 22+, puis exécuter `npm install`, `npm run build`. Remplacer les fichiers publiés par le contenu de `dist`.

Proposition indépendante. La scène lounge est générée à partir des portraits officiels. Les photos, descriptions et prix des biens proviennent de Qleïa ; leur disponibilité est à confirmer sur les annonces officielles.
